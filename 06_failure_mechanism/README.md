# Failure-mechanism diagnostics

This directory retains the composition-warp diagnostic because it has its own executable sub-experiments and compact evidence that are not naturally part of the main training workflows.

The analysis asks whether source-domain factor effects can be additively composed to predict the held P4 geometry. It includes:

- source-domain factor-interaction diagnostics;
- a noise-floor composition and retraining experiment;
- a peak-warp / collision diagnostic.

These are supporting mechanism analyses. They do not replace the canonical Strict-DG benchmark, and they do not establish a unique physical cause of P4 failure.

Start with [composition_warp/composition_warp_summary.md](composition_warp/composition_warp_summary.md).
