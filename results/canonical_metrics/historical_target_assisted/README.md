# Historical target-assisted reference

This directory preserves a compact numerical record from a **historical representation carrier** in which full P4 outcomes influenced readout promotion.

The retained historical result is approximately:
- Accuracy: **0.577143**
- Macro-F1: **0.583569**

This is not a Strict-DG benchmark and not an independent target test. The historical carrier has a different development lineage from canonical C1, and the same P4 corpus influenced selection and final reporting. It therefore does **not** establish that canonical C1 contains substantial recoverable P4 information.

The same historical carrier had already recorded a substantially higher source-only-selected P4 score than canonical C1 before retrospective readout promotion, so the cross-lineage gap cannot be attributed to target access alone.

Files retain the historical aggregate metrics, per-seed metrics, class recall, selected readout record and confusion matrix. Use them only with the access and lineage boundary above.
