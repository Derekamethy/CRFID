# Result status

Scientific classification: `FEASIBILITY_FAILURE_NOT_PERFORMANCE_FAILURE`.

The preregistered cross-position pairing gate retained only **2,100 / 4,200 = 50%** of required lawful training parents, below the required **>99%** threshold. Execution therefore stopped before development training and before any P4 performance evaluation.

This result identifies an incompatibility between the frozen split and the controlled Mixup pairing design. It is not evidence that Mixup itself performs poorly.
