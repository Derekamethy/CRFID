# Pre-DG familiar-condition baseline

These retained results provide historical context for learnability when acquisition conditions are represented during development.

The Paper4 grouped familiar-condition evaluation reached mean Accuracy about **0.7344**. This establishes familiar-condition learnability; it is not an estimate of transfer to a completely held reader geometry.

The retained files include grouped/leave-domain summaries and the compact reproduced aggregate metrics. They are used only as context for the later Strict-DG comparison.
