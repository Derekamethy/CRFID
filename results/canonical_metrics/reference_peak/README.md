# Reference-peak supporting evidence

Frequency-domain peak analysis is retained as supporting physical context, not as the primary transfer explanation.

The supplied 281-point representation can only be **conditionally mapped to approximately 5-8 GHz** because the authoritative original frequency vector and exact crop indices are unavailable.

The preregistered four-peak descriptor had a global missing-frequency rate of about **11.7%**, above the 5% extraction-validity gate. P4 peak missingness was the **lowest** among the four positions, so missing peaks do not explain the held-P4 transfer collapse.

The retained reconstruction files document the conditional frequency/peak mapping; they should not be treated as fabrication criteria or proof of a unique RF mechanism.

See [SOURCE_DOMAIN_PEAK_SEPARABILITY.md](SOURCE_DOMAIN_PEAK_SEPARABILITY.md) for the source-only **13/252 (5.16%)** separability analysis and threshold sensitivity.
