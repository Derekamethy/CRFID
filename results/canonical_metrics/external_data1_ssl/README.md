# External-data SSL follow-up

This source-only follow-up tested whether self-supervised pretraining using Data1 could improve the sealed Paper4 P4 evaluation.

The matched supervised-only treatment T0 remained the best registered primary treatment with mean head Macro-F1 about **0.12394**. None of the SSL treatments produced a reliable, stable improvement over that control.

This is a scoped negative result for the tested pretraining treatments, not a claim that self-supervised learning cannot help in other designs.
