# Matched target-assisted diagnostic

This controlled study isolates the effect of allowing P4 validation information to select among the same frozen source-fitted readouts.

For A1 target-informed selection versus A0 source-only selection:
- Mean Macro-F1 difference: **+0.002304**
- 95% bootstrap interval: **[-0.001057, +0.006679]**

The interval crosses zero, so the study does not establish a reliable selector gain.

The A2 near-perfect linear-rule result belongs to a permissive within-condition setting in which physical conditions are represented across target partitions. It demonstrates interpolation under dependence and must not be interpreted as unseen-condition transfer.
