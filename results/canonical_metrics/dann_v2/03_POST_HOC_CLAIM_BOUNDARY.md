# Post-hoc claim boundary

DANN v2 was designed after P4 outcomes from DANN v1 and other research branches were historically known. It is therefore a governed post-hoc follow-up, not pristine never-before-seen target confirmation.

The operational boundary remains strict: v2 training, lambda selection, checkpoint selection, epoch selection, source-mechanism gating, and retry decisions use P1-P3 only. If the source gate passes, final P4 evaluation is frozen before re-access.

Approved wording: "DANN v2 is a governed post-hoc follow-up whose model development and selection use P1-P3 only, while final P4 evaluation is frozen before re-access."
