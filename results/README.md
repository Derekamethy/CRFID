# Results

The public result tree contains compact evidence for the final scientific analyses. Raw Tyndall/Paper4 measurements are not distributed.

Start with [`canonical_metrics/README.md`](canonical_metrics/README.md) for the experiment index. Each branch should be interpreted only under its stated information-access regime and matched comparator; absolute scores from different branches are not automatically comparable.The canonical Strict-DG evidence is in [`canonical_metrics/strict_dg/`](canonical_metrics/strict_dg/). It includes final metrics, five checkpoints, preprocessing state, source-selection summaries, and confusion matrices.

Selected `.npy`, `.npz`, `.pt`, and `.pth` files under `canonical_metrics/` are intentional scientific evidence. New experimental outputs should be written outside the tracked result tree, for example through an external `CRFID_OUTPUT_ROOT`.
