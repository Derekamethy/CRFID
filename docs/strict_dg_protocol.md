# Strict Source-Only DG Protocol

P1–P3 features and labels may be used for development, candidate comparison and model selection. P4 features and labels are forbidden until the complete recipe is frozen and verified. The selected recipe uses first differences, source-only featurewise population standardization, a GroupNorm 1-D CNN, AdamW and five equally reported seeds. Once target access occurs, recipe changes are prohibited.

The implementation is source-only. The broader programme had previously studied P4, so the held-out evaluation is retrospective rather than a claim of a historically untouched target.
