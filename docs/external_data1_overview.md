# External Data1 overview

Data1 is an independently acquired four-class dataset used only to validate
pipeline portability. Its exact raw authority has 9 files, 12,250 rows, class
counts `[3150,3150,3150,2800]`, and 1,601 signal values per row.

The task is local to Data1. No seven-class weights, labels, predictions, or
preprocessing states are used. The documented 2.1–10.6 GHz range does not
establish exact cross-dataset axis identity, and no cross-dataset class mapping
is available.
