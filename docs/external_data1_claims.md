# External Data1 claim boundary

Supported after successful independent verification:

- Data1 is learnable under the frozen within-Data1 split.
- The canonical CNN training/evaluation pipeline is applicable to Data1.
- First-difference preprocessing is not supported as superior on Data1.
- The selected Data1 authority is independently acquired relative to the source
  project data.

Not supported:

- direct external validation of a seven-class model;
- cross-dataset zero-shot transfer, adaptation, or class mapping;
- exact physical-axis equivalence;
- improvement to strict source-only DG or any other dataset result;
- generalization of the PCA result beyond the frozen Data1 split.
