# OpenEMS Physical-Redesign Protocol

The geometry is assumption-bounded unless fabrication-authoritative geometry is supplied. The nominal model uses four parallel resonators on a circular Rogers 5880 substrate. Real VNA calibration is unavailable unless measured calibration data are supplied.

The existing conclusion is `NOT_CONFIRMED`. Confirmation requires global minimum pairwise separation to improve without merely moving the bottleneck, plus resonance and convergence gates. The public simulator adapter never launches OpenEMS during import, configuration validation or dry-run planning.
