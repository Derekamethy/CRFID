# OpenEMS physical redesign

This workflow evaluates assumption-bounded CRFID geometry modifications using OpenEMS and conservative worst-pair separation gates.

The confirmed baseline minimum pair separation was about **3.1929 dB** and the selected candidate about **3.2146 dB**, a change of approximately **0.681%**. This is below the preregistered **5%** practical-improvement gate, so the redesign status is **NOT_CONFIRMED**.

The simulation is exploratory: no hardware classification improvement was validated and fabrication is not recommended from this evidence. The robust R2 follow-up executed zero new governed simulations because compatible solver bindings were unavailable in the locked runtime.

Compact evidence is in `results/canonical_metrics/openems_redesign/`.
