# Failure-mechanism analysis

This workflow examines why source-trained CRFID classifiers degrade under geometry shift. It analyzes frozen signals, embeddings, predictions and labels for separability, position encoding, representation entanglement, confusion structure, peak behaviour and physical descriptors.

It does **not** adapt or retrain the evaluated classifier. Its outputs are diagnostic evidence only and are interpreted alongside the fixed-position, angle-distance and representation-probe studies.
