# Example-data policy

No measured or row-derived example is included because publication rights for
the underlying measurements have not been established. Use the synthetic
fixtures in `tests/synthetic/` and `tests/integration/` for data-free execution.

An externally supplied dataset must satisfy `data/schemas/datasets.json` and
the corresponding configuration under `configs/data/` or
`configs/external_data1/`. Keep it outside Git and select it through the
documented environment variables.
